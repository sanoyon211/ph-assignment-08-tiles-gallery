# 🏠 Tile Gallery

## Purpose
A premium web application to showcase and explore a curated collection of artistic tiles. Users can browse tiles, view details, and manage their personal profiles.

## 🌐 Live URL
[https://tiles-gallery-ph.vercel.app](https://tiles-gallery-ph.vercel.app)

## ✨ Key Features
- 🔐 Secure Authentication (Email/Password & Google Login)
- 🖼️ Browse full tile gallery with search functionality
- 🔍 View detailed information for each tile
- 👤 Personal profile page with update feature
- 📱 Fully responsive (Mobile, Tablet & Desktop)
- 🎠 Interactive banner slider (SwiperJS)
- 🔒 Private routes for authenticated users only
